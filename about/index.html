What is Liquid Space?

A Hexo theme built around spatial liquid glass:

  • VisionOS-style floating capsule navigation
  • Specular rim light and micro-noise acrylic materials
  • Aurora canvas with saturation-boosted backdrops
  • Spring / jelly interaction physics

Stack

  1. Hexo + EJS
  2. Tailwind CSS design tokens
  3. Vanilla JS (no jQuery)
